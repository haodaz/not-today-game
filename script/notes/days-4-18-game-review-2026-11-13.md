# 4–18 天的「大活」再看一遍：哪些能像 2048 和 1–3 天那样做成一个游戏（2026-11-13 夜）

作者的要求：「重新 review 一下 4–18 的所有游戏任务，有没有能像 2048、1–3 天那样做的更好，加入更多惊喜和致敬」。

现在的情况：4、5、6、8、11、12、14、16、17 都是**证据板**一个模子（找句子贴格子），7、9、15 是**会议回放 + 模板**，10 是对比页，13 是 2048。
一个模子用九次，玩到第三天就麻了。下面每一天给一个**不同的老游戏**当壳，规则照搬原作，赢了 = 交付物成形，输了 = 让克总帮忙（结算的两条路不变）。
致敬的池子：掌机和功能机时代的东西（她小时候的那些），配合「小鸡 = 鸡娃」这条线，小鸡在每个游戏里客串一次。

## 成本和顺序

每个壳是一个独立的纯引擎 + 一个全屏视图 + 一个 settlement（结算层已经有了），跟 2048 一样的做法：**一天一个，一天一个模子**。按「做起来快、反差大」排：

1. **12 俄罗斯方块**（规则最熟，格子就是值班表，一天能出）
2. **8 扫雷**（日历格子现成）
3. **16 节奏**（随身听已在游戏层；音频已有）
4. **17 扭蛋**（最小）
5. **4 拼图 / 5 连连看 / 6 贪吃蛇**（三连，同一批素材）
6. **9 推箱子 / 7 吃豆人 / 15 打地鼠 / 14 跑酷**（需要新画面）
7. **11 天平**

每一个都保留：launch 页（已有）、结算两条路（已有）、失败让克总帮忙（已有）、小鸡战斗按钮（已有）。
