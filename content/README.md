# content/

Everything that is story lives here as data. Code under `src/` reads and renders it and never contains a story string.

Authored by Claude (Anthropic) with the author, Elodie Hao Liu. The eighteen-day story, the setting bible and the Chinese gamebook these files are derived from were written before the hackathon and are published at https://github.com/haodaz/nottoday (CC BY-NC-ND 4.0). The files in this folder are a data form of that pre-existing work. All game code in this repository is new and was written during the Kiroween 2026 submission period.

Hand-written constants that code must never generate or edit are marked `_note` at the top of each file.
