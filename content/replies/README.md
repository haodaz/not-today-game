# replies/ — 每天 × 每个人 × 每个词 → 回复

玩家对每个人能说的话是一张小表（`fine 好。` `received 收到。` `whatever 哪都行。` `salary 最近有钱发工资吗。`，后期多出 `lol 哈哈` `what-llm 你换模型了`），物件借的词按天出现（`wait 等` `no 不` …）。公司群、小张、老周前期有全键盘，表里用 `free` 一格代表「自己打的字」。玩家一定会把每个词对每个人试一遍，这张表就是游戏感的来源：谁回、谁不回、谁打岔。

文件：`day-NN.json`

```
{
  "day": 1,
  "recipients": {
    "boss": {                       // boss | partner | group | xiaozhang | laozhou（家人在 family/）
      "fine": {
        "status": "reply",          // reply 回了 | read 已读不回 | typing 正在输入然后没了 | recalled 回了又撤回 | silence 连已读都没有
        "lines": [ { "who": "boss", "t": "09:14", "text": "…" } ],   // who 可以是 boss/partner/laozhou/xiaozhang/member（群里别人）/kuro
        "interrupt": { "who": "boss", "where": "group", "t": "09:15", "text": "…" },   // 打岔：另一个会话里冒出来的东西，把这件事抹过去
        "effects": { "san": 0, "flags": ["…"] },
        "inner": "…"                // 可选：内心一行（斜体，不发出去）
      }
    }
  }
}
```

规则：
- 老板从不谈钱。`salary` 对老板永远是 `read`，差别只在多久已读、之后谁来打岔。
- 合伙人回卡片不回话。
- 群里的人一批一批换：第二轮回（d4–6）起群里的回复开始「客气」。
- 小张叫你 `{calledBy}`（默认老大），时间戳从不整点。老周歪楼，什么都能拐到吃饭上。
- 每个词都要有东西可看，哪怕是「已读」出现得比平时快一秒。
- 回复里不出现「它」的名字以外的任何新世界词汇；恐怖在格式里（已读、语音时长、转发卡片、撤回）。

## 补充（2026-10-31 下午）

- 每个人每天多一个 `incoming`：当天对方主动发来的消息，`kind` 是 work（收发活）/ money（钱）/ private（私事）/ odd（不对劲的东西：零秒语音、嚼东西的声音、三张一样的风景）。玩家不回也会收到；这是「每天不只两条」的来源。
- `status: gone`：这个词今天从菜单上灰掉了（阶段收缩或物件收回），`inner` 写玩家看见它灰掉时的那一行。
- 家人在 `family.json`，自己的四句：`eaten 吃了。` `busy 在忙。` `fine 好。` `unpaid 还没发。`，物件借的词同样可用。`{nick}` 只在家人这里出现。
- 18 天的走向：1–6 缓慢变化；7–12 沉默、含糊、奇怪的声音、重播；13–15 换人、温柔、知道不该知道的事；16–18 只剩好话。每天都不一样，不重复用同一种怪。
- 还没写：客户（client）那一列。客户在故事里只通过老板和账本出现，暂不单列。

## 补充（2026-11-01）

- 家里变成两个群：`family.json` 是父母群（没前缀的是妈，`father：` 是爸），`clan.json` 是大群「相亲相爱一家人」（大姨打探、二舅和表弟堂姐炫耀、小姑转发干扰、姥姥话短没标点）。大群自己的词：fine / lol / received / thanks + 物件借的词。
- 人名前缀「老周：」「大姨：」决定气泡上的名字和头像；有脸的在 `content/npc.json`，没有的用剪影。
