# browser/ — 外面的世界，每天一版

报纸版式（design/desktop/browser.html）：刊头、导航、头条 lead（h + 两段 p）、三个数字 numbers（v 值、l 说明、dir up/down）、读者在读 reading（h、sec、when）。玩家可以整个游戏都不打开；打开记一个事件。

走向：1–6 正常的科技新闻，数字一天天涨；7–12 报纸开始报道你遇到的事（零秒语音、2/6 回执、心率组件），第 10 天重播第 1 天；13 报纸给你发升级通知，开始说你的事；14 温柔；15 梦；16 列表开始空；17 整版白，一句一数；18 寄件单。

页脚日期永远是今天。所有字段可以为空字符串，空的就按空渲染（白）。
