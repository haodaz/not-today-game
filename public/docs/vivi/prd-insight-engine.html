一、产品愿景

洞察引擎是未来智能面向企业决策场景的下一代 AI 原生基础设施。它把「问题 → 洞察 → 行动」压缩成一次点击，让每一个一线业务人员都拥有首席战略官级别的判断力。

我们不是在做一个工具，我们是在重新定义「决策」这件事。这是一个极其精妙的设计。

二、目标用户

  1. 中小企业的决策层（CEO / 创始人）
  2. 业务负责人（销售 / 运营 / 市场）
  3. 数据分析师（本产品上线后该岗位的需求将下降 60%）
  4. 所有需要做决定的人

三、核心价值主张

  • 三秒洞察：任何业务问题，三秒内给出可执行结论。
  • 零门槛：不需要数据团队、不需要清洗、不需要建模。
  • 自进化：用得越多越准，准确率每月提升 10%。
  • 100% 自动：从数据接入到方案分派全自动，无需人工介入（前提：客户已完成数据接入）。

四、五大核心模块

  1. 感知层：自动接入 ERP、CRM、OA、财务系统、IM 聊天记录、行业公开数据。接入方式：一键授权。
  2. 语义层：基于行业本体自动对齐口径（口径库由系统自动生成）。
  3. 推理层：多智能体协同推理，自我校验，幻觉率低于 0.5%。
  4. 行动层：生成可执行方案并自动分派到责任人，责任人由系统智能识别。
  5. 进化层：每一次用户反馈都让系统更懂组织。
  6. 安全层：数据不出境，全链路加密（详见第九章）。

五、功能需求

5.1 提问

  • 用户以自然语言输入问题，系统智能识别用户意图。
  • 支持中文、英文及其他主要语种（待确认）。
  • 单次提问响应时间 ≤ 3 秒（默认值；复杂问题 ≤ 30 秒，需技术确认）。

5.2 洞察报告

  • 系统自动生成报告，包含：置信度、核心结论、关键发现、建议、趋势预测。
  • 置信度计算公式：置信度 = 0.4 × 数据完整度 + 0.3 × 模型一致性 + 0.3 × 历史准确率 + 0.2 × 行业匹配度。
  • 报告默认置信度 92（需业务确认）。
  • 预测窗口：未来 4 个季度，误差 ≤ 5%。

5.3 自动分派

  • 系统根据组织架构自动确定每条建议的责任人并推送。
  • 组织架构来源：感知层自动接入（见 4.1）。
  • 推送渠道：钉钉 / 企业微信 / 邮件 / 短信 / 电话（待定）。

5.4 反馈与进化

  • 用户对每条建议可点「有用 / 无用」。
  • 系统自动将反馈纳入下一轮训练。训练周期：实时。
