# motion.md — 手感规格（Kiro 做「polish」那一段的依据；作者 2026-11-01：现在是没加 CSS 的 HTML，要有手感）

统一原则：所有东西都从它在画面里的位置来、回它的位置去；没有东西凭空弹出。时长短、曲线缓出（cubic-bezier(.2,.8,.2,1)），退场比进场快 30%。

| 交互 | 动作 | 时长 |
|---|---|---|
| 点桌面条上的手机 | 房间压暗到 55%；手机从桌面条那一格升到正中，**不倾斜**（作者 11-01：手机屏不能歪；物件保留 3°）；屏幕亮起（白闪一下 120ms）；软件在它的屏幕里 | 压暗 200ms，升起 320ms |
| 放下手机 | 点屏幕外；原路缩回那一格；房间亮回来 | 220ms |
| 点物件（小鸡、寻呼机…） | 同手机：壳升到正中，屏幕是它自己的 canvas（整数像素）；按键可点，按下去有 1px 位移和咔的声音 | 320ms |
| 夜里举起物件对着缝 | 从举起状态再往上、往缝的方向推 20%，背景切成缝的粉光，手不画 | 600ms，缓入缓出 |
| 清单打勾 | 方框先填色 80ms，再划一道；完成的条目 400ms 后收进「已做 N 件」 | 80 + 400ms |
| 清单新条目出现 | 从上一条下面淡入 + 下移 6px；「不是你写的」条目**没有任何区别** | 240ms |
| 对话框 | 整框淡入 160ms；每行逐字出现（每字 18ms，点击立即补完）；内心行斜体、慢 1.5 倍；声音行先响后出字（音效在字前 400ms） | — |
| 选择 | 三条竖排从下往上依次淡入，间隔 60ms；选中那条留下，其余淡出 | 160ms |
| 门铃 | 音效先响；400ms 后清单冒出「去拿。」；再 300ms 对话框「叮咚。」 | — |
| 房间 ↔ 桌面 | 房间视角镜头推向显示器 400ms，同时桌面从屏幕位置放大到全屏；回去反向 | 400ms |
| 左屏 ↔ 右屏 | 横向推移 240ms，另一块屏露的那条跟着动 | 240ms |
| 克总小窗 | 新一句：从本体那里冒出来（本体先 busy 200ms，再 think，再小窗出字）；夜里 blink 是 2s 周期的光晕 | — |
| 克总本体 | 状态切换一律 300ms 透明度交叉；bob 3s 周期 ±3px；crawl 时沿底边移动 1.2s | — |
| 关机 | 两块屏各自暗下去（先右后左，相隔 150ms）；台灯色温保留；桌面条收起，只剩缝 | 600ms |
| 躺下 | 画面向上升一点再黑 800ms；夜里的对话框在黑里出字；「今天过去了。」停 1.5s；下一天从白开始淡入 | — |

声音（public/sfx/，都短）：doorbell、pager-buzz、chick-beep（方波）、lamp-click、chain、lock、key-press（物件按键）、rain-loop（循环，很轻，关机后变大一点）。
